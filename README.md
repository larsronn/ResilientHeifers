# ResilientHeifers
Supplementary material to the manuscript: Resilience of heifers introduced to the milking herd.

The file ResilienceResults_in_markdown.pdf shows the details of the statistical analysis. You also find html and Quarto versions (in the files ResilienceResults_in_markdown.html and ResilienceResults_in_markdown.qmd) used to generate the PDF.

The input data used for the analysis are found in txt-files and the R code to read these files is given in the qmd-file.
